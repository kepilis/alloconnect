Настройки
Профиль

Квадрат по центру картинки; гифка — как есть (до 1 МБ). Друзья увидят при следующей связи.

Звонок и микрофон

Выключено — как обычный звонок: звук в динамике у уха, у уха экран гаснет сам. «Громкая» в звонке переключает. Когда друг показывает экран — включается громкая.

Звук входящего
Мелодия: стандартный

Своя мелодия звучит, когда приложение открыто; в фоне Android играет мелодию уведомления.

Микрофон

В звонке держи кнопку микрофона и говори, отпустил — друг тебя не слышит. Удобно в шумном месте и в играх.

Связь в фоне

Друзья смогут позвонить, даже когда приложение закрыто или экран выключен. В шторке будет висеть уведомление «alloconnect в сети». Тратит заметно больше батареи. Без этой опции звонить можешь ты сам, а друзья — пока приложение открыто.

Демонстрация с телефона

Плавный режим уменьшает разрешение на телефонах с программным кодированием. Изменение применяется при следующем запуске демонстрации.

Поверх моего экрана

Пока показываешь экран, рисунки друга видны поверх любых приложений; касания проходят сквозь них. Друг увидит свои рисунки и в картинке (Android записывает их вместе с экраном).

Текстовый — чёткая картинка, но мало кадров: для документов, чатов и мобильного интернета. Звук телефона — с Android 10; голос звонка в него не попадает. Некоторые приложения запрещают захват своего звука.

Просмотр демонстрации

Меньше — экономнее для мобильного интернета, больше — чётче картинка при провалах сети. На ПК по умолчанию 2500.

Повторы

Пока смотришь стрим друга — ⏪ сохраняет последние секунды в MP4: оставить себе или отправить другу. Тратит немного батареи, пока идёт стрим.

Оформление
Стикеры

Свои наборы картинок и гифок — кнопка 🙂 у поля сообщения. Чужой стикер из чата — ＋ на нём (набор «Полученные»).

YouTube

Проверяю сессию…

Вход выполняется на сайте YouTube. Если Google отклонит его, можно импортировать файл cookies.txt. Сессия хранится только на этом устройстве.

Сеть и подключение

Пакеты остаются зашифрованными. Настройки VPN не меняются.

    Обновления

    Новая версия берётся с GitHub и ставится только после проверки подписи. Установку подтверждаешь ты в окне Android; в первый раз Android попросит разрешить alloconnect устанавливать приложения.

    История

    Удаляется только у тебя. С одним другом — 🗑 в его чате.
