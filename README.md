# Файлы автообновления alloconnect

Отсюда alloconnect сам скачивает новую версию: `app.asar`, `alloconnect-helper.exe` и `update.json`.
`update.json` подписан ключом автора (Ed25519). Программа ставит обновление, только если подпись
и контрольные суммы файлов сходятся. Вручную качать эти файлы не нужно.

Текущая версия: 1.20.0
