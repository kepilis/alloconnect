# AlloConnect для Android 0.16.17

[Скачать APK для ARM64](alloconnect_android-0.16.17-arm64-v8a.apk?raw=1)

В разделе «Настройки → Аккаунт и устройства» появилась кнопка «Отвязать устройство».

Первую сборку новой линейки установите вручную. Android установит её рядом с 0.16.16. У каждой версии своё локальное хранилище. Дальнейшие обновления новой линейки приходят из этой ветки.
