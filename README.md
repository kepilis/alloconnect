# alloconnect для Android — обновления

Текущая версия: **0.15.6** — [alloconnect_android-0.15.6-arm64-v8a.apk](alloconnect_android-0.15.6-arm64-v8a.apk?raw=1)

Входящий обычный и групповой звонок больше не перекрывается формой добавления друга и клавиатурой; введённый текст сохраняется. Улучшена плавность групповой демонстрации: при перегрузке нескольких программных потоков разрешение подстраивается, после отключения лишнего просмотра восстанавливается.

Архитектура: **arm64-v8a**. Приложение проверяет подпись Ed25519, размер и SHA-256 APK; установку подтверждает пользователь в окне Android.
