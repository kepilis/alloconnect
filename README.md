# AlloConnect для Windows 1.22.31

Исправлен приоритет GPU для процесса захвата экрана и кодировщика.

При перегрузке демонстрация сначала снижает FPS, сохраняя разрешение. Адаптация нагрузки больше не урезает потолок битрейта; восстановление разрешения возможно и при продолжающейся нагрузке игры.

Расширена техническая диагностика захвата, ограничений отправителя и приоритета GPU.

Обновление доступно через «Проверить обновления».
