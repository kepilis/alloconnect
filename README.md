# alloconnect — обновление 1.22.5

Исправлено подключение общего аккаунта между устройствами, которые уже есть друг у друга в друзьях: привязка больше не ждёт повторного запроса дружбы. Сравнение кода и подтверждение объединения сохранены. Ошибки подключения теперь видны в начале страницы.

Обновите оба устройства. Если они уже добавлены в друзья, после ввода кода сразу появляется взаимная проверка; новый запрос дружбы не нужен. Данные передаются после проверки кода и подтверждения результата на обоих устройствах.
