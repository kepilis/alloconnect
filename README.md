# AlloConnect для Windows 1.22.17

Саундпад для Windows: галочка «В виртуальный микрофон» автоматически подключает VB-CABLE и смешивает звуки с голосом. При первой установке драйвера Windows запрашивает подтверждение.

[VB-CABLE от VB-Audio](https://vb-audio.com/Cable/) распространяется как donationware.

Обновление доступно через «Проверить обновления».
