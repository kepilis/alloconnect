# alloconnect — обновление 1.21.8

Добавлено использование входа в YouTube из выбранного браузера: выключено по умолчанию, включается с явного согласия.
Автоматическое определение браузера по умолчанию; доступ можно отключить в настройках YouTube.
Понятные ошибки возрастных ограничений, блокировки и защиты куки; куки не экспортируются в файл и не записываются в лог.

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой. Инструменты YouTube скачиваются проверяемым служебным пакетом при первом использовании.
