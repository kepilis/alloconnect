# alloconnect — обновление 1.21.9

Добавлена панель загрузок: процент, скачанный и общий объём для инструментов YouTube, движка и модели удаления фона.
Проверка файлов, установка и запуск нейросети показываются отдельно; готовность появляется только после завершения подготовки.
Прогресс скачивания YouTube-видео и звука, понятные состояния ошибки и отмены; панель можно скрыть и открыть снова.

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой. Инструменты YouTube скачиваются проверяемым служебным пакетом при первом использовании.
