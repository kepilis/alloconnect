# AlloConnect для Windows 1.22.29

В «Настройки → Аккаунт и устройства» добавлена кнопка «Отвязать устройство» с подтверждением. Профиль, контакты, переписка, вложения и настройки сохраняются на этом ПК.

Синхронизация и восстановление аккаунта больше не открывают окно при запуске. Панель доступна из настроек.

Обновление доступно через «Проверить обновления».
