# alloconnect для Android — обновления

Текущая версия: **0.13.6** — [alloconnect_android-0.13.6.apk](alloconnect_android-0.13.6.apk?raw=1)

Контрольная сборка возвращает код Android 0.13.3 для проверки звонков с Windows 1.21.1. Номер версии повышен, чтобы установить её поверх 0.13.5.

Отсюда приложение берёт обновления само (⚙ → «Обновления»): `update-android.json` — описание версии,
подписанное ключом автора (Ed25519); приложение проверяет подпись, размер и SHA-256 файла и что APK подписан
тем же ключом, что установленное приложение. Ставит всегда пользователь — в окне Android.

Первый раз — скачай APK по ссылке выше и открой его на телефоне.
