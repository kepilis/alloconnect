# alloconnect — обновление 1.21.20

На стартовом экране справа сверху добавлена кнопка «Проверить обновления». Она запускает ту же проверку и установку обновления, что и кнопка «Проверить сейчас» в настройках; результат проверки отображается рядом с кнопкой.

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой.
