# AlloConnect для Android 0.16.20

[Скачать APK для ARM64](alloconnect_android-0.16.20-arm64-v8a.apk?raw=1)

Окно аккаунта больше не открывается при запуске приложения. Синхронизация и восстановление продолжаются в фоне. Панель доступна в «Настройки → Аккаунт и устройства».

Обновление новой линейки `com.alloconnect.alo`, versionCode 57. Подпись и ключ обновлений сохранены. Старая линейка `com.alloconnect.app` не менялась.
