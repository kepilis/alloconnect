# alloconnect для Android — обновления

Текущая версия: **0.15.0** — [alloconnect_android-0.15.0-arm64-v8a.apk](alloconnect_android-0.15.0-arm64-v8a.apk?raw=1)

Отсюда приложение берёт обновления само (⚙ → «Обновления»): `update-android.json` — описание версии,
подписанное ключом автора (Ed25519); приложение проверяет подпись, размер и SHA-256 файла и что APK подписан
тем же ключом, что установленное приложение. Ставит всегда пользователь — в окне Android.

Архитектура этой сборки: **arm64-v8a**. Для ARM64-телефонов, включая POCO X6 Pro. На ARMv7/x86 эту сборку устанавливать не следует.

YouTube: вход и сохранение сессии, импорт cookies.txt, получение видео по ссылке, прогресс и отмена. Очередь сообщений, статусы, групповой чат, исправления демонстрации и передачи медиа. ARM64. Вход Google на Android ещё требует проверки на устройстве.

Первый раз — скачай APK по ссылке выше и открой его на телефоне.
