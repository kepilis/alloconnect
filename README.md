# alloconnect — обновление 1.21.10

Единая панель загрузок: инструменты YouTube, нейросети, медиа по ссылкам, входящие файлы и обновления с GitHub/от друга.
Проценты и объём, отдельные этапы проверки/установки, понятные ошибки, отмена и повторные попытки; при неизвестном размере виден скачанный объём.
Файлы в чате показывают проценты и объём; неполные и избыточные передачи не отмечаются готовыми.

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой. Инструменты YouTube скачиваются проверяемым служебным пакетом при первом использовании.
