# AlloConnect для Windows 1.22.30

Демонстрация получает повышенный приоритет GPU и CPU на время показа. При длительной перегрузке нагрузка захвата снижается, после восстановления качество возвращается автоматически.

Уточнены предупреждения об ограничении битрейта WebRTC, добавлена диагностика демонстрации.

Обновление доступно через «Проверить обновления».
