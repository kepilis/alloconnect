# AlloConnect для Android 0.16.21

[Скачать APK для ARM64](alloconnect_android-0.16.21-arm64-v8a.apk?raw=1)

- После отправки сообщения фокус и клавиатура сохраняются; чаты и окна учитывают доступное место.
- Фронтальная или задняя камера выбирается перед включением.
- Доработаны запись, просмотр и сохранение повтора. «Смотреть вместе» доступно внутри повтора.
- Исправлены черновики, действия «Назад», остановка скрытого медиа и читаемость системной полосы.

Новая линейка `com.alloconnect.alo`, versionCode 58. Сертификат APK и ключ обновлений сохранены. Проверено обновление с 0.16.20 в эмуляторе Android 16, а также звонки и совместный просмотр с Windows 1.22.33. Физический телефон не проверялся.
