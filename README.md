# alloconnect — обновление Windows 1.22.8

Автообновление yt-dlp на ПК при использовании YouTube: проверка стабильной версии раз в 6 часов, повтор после ошибки через 15 минут. Проверяются PGP-подпись разработчиков, SHA-256, размер и запуск. Сохраняется предыдущая рабочая версия; FFmpeg и нейросети не меняются.

Установленные приложения получают эту версию через «Проверить обновления». yt-dlp проверяется при загрузке медиа с YouTube; при отсутствии связи используется прежний загрузчик.
