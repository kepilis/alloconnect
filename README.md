# alloconnect — обновление Windows 1.22.13

Снижено потребление памяти в истории чатов Windows. Изображения и медиа читаются с диска по мере использования, а синхронизация кэширует информацию о вложениях без хранения их содержимого в оперативной памяти.

Установленные приложения получают эту версию через «Проверить обновления».
