## Возможности

**Связь**
- Исправлен сбор сетевых адресов: сохраняются TCP-кандидаты и найденные резервные маршруты, устаревший адрес STUN очищается
- Добавить друга — один короткий код через любой мессенджер, дальше звонки из списка друзей в один клик
- Групповые звонки до 6 человек: голос, чат, файлы, показ экрана, рисование и управление; сохранённые группы с историей чата
- Если двое в группе не соединяются напрямую (строгий NAT, мобильная сеть) — их звук, экран, камеру и чат пересылает третий участник
- Вышел из звонка — можно вернуться одной кнопкой
- Прямое соединение (WebRTC), шифрование ключом пары, пробивка NAT, UPnP; запасные STUN-серверы
- Автоматическое переподключение при обрыве сети
- Работа в трее, автозапуск, свой звук звонка
- Свои уведомления в стиле темы: аватарка (гифки играют), картинки и гифки сразу видны
- Друзья и переписка с ними — и во время звонка (кнопка 👥)
- Темы оформления: стандартная, неоновая ночь, терминал, стекло, ретро-пиксель, манга, космос, чертёж, ретро-ОС, тетрадь, газета
- Настройки по разделам; сворачивание на панель задач или в трей

**Голос**
- Шумоподавление (RNNoise), эхоподавление, автогромкость
- Рация (push-to-talk) на клавишу или кнопку мыши, работает в играх
- Приглушение других программ, пока идёт разговор
- Саундпад с горячими клавишами; звук можно взять из видео — просто перетащить его в саундпад
- Горячие клавиши (меняются в настройках): микрофон, звук, шумодав, повтор, «стоп всё», «убрать всё с моего экрана»

**Камера и окна**
- Вебкамера в звонке на двоих (друг крупно, своя картинка в углу) и в группе (в плитке участника, при показе экрана — в углу)
- Демонстрацию, камеру и чат можно свернуть (у свёрнутой демонстрации нет звука); в группе — участников и чат
- По желанию — свободное расположение окон: перемещать, менять размер, закреплять, прицеплять друг к другу, выносить в отдельное окно

**Демонстрация экрана**
- Весь экран или отдельное окно со звуком только этого окна, до 1440p60
- Автовыбор кодека по возможностям обеих видеокарт (AV1, H.265, H.264, VP9, VP8)
- Повтор последних 10–60 секунд одной клавишей с сохранением в MP4, по желанию со звуком
- При показе всего экрана окно alloconnect в показ не попадает (нет «зеркала»)
- Ширина чата рядом с демонстрацией меняется мышью; рамку вокруг стрима можно выключить

**Поверх экрана друга**
- Указка, рисование (карандаш, маркер, линия, стрелка, прямоугольник, овал; толщина и цвет), реакции
- Картинки, гифки и видео (до 1 минуты и 100 МБ) с выбором места, размера, поворота и громкости; фон у картинок и гифок можно убрать (однотонный — сразу, человека или предмет — нейросетью, скачивается один раз); видео можно перетащить прямо со страницы (Pinterest и др.)
- Удалённое управление мышью, клавиатурой и геймпадом — только с разрешения

**Чат и файлы**
- Сообщения, картинки и файлы любого размера, в звонке и без звонка; отметки «доставлено» ✓ и «прочитано» ✓✓
- Стикеры: свои картинки и гифки, наборы — из файлов или целой папкой
- Реакции, ответы с цитатой, правка и удаление своих сообщений, поиск по истории
- Локальная история переписки вместе с файлами (до 200 МБ каждый)
- Аватарки: картинка или гифка, можно перетащить; большая сама уменьшается
- Статус «во что играю» (по желанию)

**Обновления**
- Автоматическая проверка и установка новых версий с проверкой подписи; откат на прошлую версию

## Установка

Распакуйте `alloconnect-X.Y.Z-win.zip` в любую папку и запустите `alloconnect.exe`. При первом запуске разрешите доступ к сети в брандмауэре.

## Сборка из исходников

```
npm install
npm start          # запуск
npm run dist       # сборка zip для Windows
```

Помощник Windows (`native/alloconnect-helper.cpp`):

```
zig c++ -target x86_64-windows-gnu -O2 -s -static -DVIGEM_STATIC -Inative/shim -Inative/vendor/ViGEmClient/include native/alloconnect-helper.cpp native/vendor/ViGEmClient/src/ViGEmClient.cpp -o native/alloconnect-helper.exe -lole32 -luser32 -lsetupapi -ldwmapi
```

Для геймпада в удалённом управлении на управляемом компьютере нужен драйвер [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases).
