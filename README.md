# alloconnect — обновление 1.21.12

Единый ввод кодов дружбы и приглашений с предварительным описанием действия; создание своих кодов в раскрывающемся меню. При отказе отдельных параметров WebRTC сохраняется настройка частоты кадров демонстрации для игры; добавлена диагностика отправителя. Прирост FPS в Death Stranding 2 пока не измерен.

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой. Инструменты YouTube скачиваются проверяемым служебным пакетом при первом использовании.
