# Файлы автообновления alloconnect

Текущая версия: **1.21.5**.

HTTPS-сигналинг и временные TURN-параметры для собственного резервного сервера. Прямой P2P сохранён; резерв выключен по умолчанию и настраивается адресом сервера. Проверены реальные звонки Amnezia и Happ VLESS/TCP/REALITY через LTE. Настройки VPN не меняются.

Приложение проверяет подпись Ed25519, размеры и SHA-256 файлов перед установкой.
