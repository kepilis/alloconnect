# AlloConnect для Android 0.16.18

[Скачать APK для ARM64](alloconnect_android-0.16.18-arm64-v8a.apk?raw=1)

Длина повтора меняется ползунком с отображением текущего значения. Запоздалый результат отправки ответа на звонок больше не завершает следующую попытку.

APK обновляет 0.16.17 новой линейки `com.alloconnect.alo`. Для перехода с 0.16.16 установите APK вручную отдельным приложением. У каждой установки своё локальное хранилище.
