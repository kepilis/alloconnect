# alloconnect — обновление 1.22.0

Общий аккаунт: профиль, контакты, переписка, вложения и журнал звонков между двумя устройствами. Настройки синхронизируются только между устройствами одного типа. Фоновая синхронизация Android, работа после офлайна и локальное восстановление до объединения. Сохранены говорящие аватарки и новое расположение кнопок.

Общий аккаунт включается через настройки → «Аккаунт и устройства». Обновите оба устройства. До объединения автоматически создаётся локальная копия для восстановления. Бета: два устройства, до 100 друзей, до 65536 записей/16 МиБ метаданных, аватар до 1 МиБ, отдельное вложение до 200 МиБ. Персональные ключи устройств сохраняются. Говорящие аватарки и новое расположение кнопок сохранены.

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой.
