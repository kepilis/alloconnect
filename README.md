# alloconnect — обновление 1.21.19

Уменьшена задержка при удалённом управлении: быстрый режим буфера с выбором плавности, отправка движений мыши без ожидания кадра интерфейса и меньшая очередь передачи файлов. Добавлен режим демонстрации 720p60. После завершения управления прежний буфер восстанавливается.

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой.
