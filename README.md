# AlloConnect для Windows 1.22.35

В личном и групповом звонке можно менять размер всех аватарок: правый клик по аватарке открывает меню с ползунком от 50 до 250%, полем точного процента и готовыми вариантами.

Размер меняется сразу и сохраняется между запусками. В маленьких окнах и плитках группы аватарки ограничены доступным местом.

Обновление доступно через «Проверить обновления».
