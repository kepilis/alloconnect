# AlloConnect для Windows 1.22.32

В окне запуска личной демонстрации добавлен выбор кодека: «Автоматически», H.264 и H.265. Это позволяет сравнить работу кодировщиков в активной игре.

При ручном выборе проверяется фактическое аппаратное кодирование. Если выбранный кодек не удалось применить или аппаратное кодирование не подтверждено, приложение показывает причину.

Сохранены игровой режим с приоритетом FPS, прежний автоматический выбор и настройки нагрузки демонстрации. Дополнена техническая диагностика качества кодирования.

Обновление доступно через «Проверить обновления».
