# alloconnect для Android — обновления

Текущая версия: **0.16.0** — [alloconnect_android-0.16.0-arm64-v8a.apk](alloconnect_android-0.16.0-arm64-v8a.apk?raw=1)

Отсюда приложение берёт обновления само (⚙ → «Обновления»): `update-android.json` — описание версии,
подписанное ключом автора (Ed25519); приложение проверяет подпись, размер и SHA-256 файла и что APK подписан
тем же ключом, что установленное приложение. Ставит всегда пользователь — в окне Android.

Архитектура этой сборки: **arm64-v8a**. Для ARM64-телефонов, включая POCO X6 Pro. На ARMv7/x86 эту сборку устанавливать не следует.

Общий аккаунт: профиль, контакты, переписка, вложения и журнал звонков между двумя устройствами. Настройки синхронизируются только между устройствами одного типа. Фоновая синхронизация Android, работа после офлайна и локальное восстановление до объединения. Сохранены говорящие аватарки и новое расположение кнопок.

Первый раз — скачай APK по ссылке выше и открой его на телефоне.

Общий аккаунт: настройки → «Аккаунт и устройства». Для начального подключения обновите оба приложения. Автоматическая локальная копия доступна в разделе восстановления. Бета: два устройства, до 100 друзей, до 65536 записей/16 МиБ метаданных, аватар до 1 МиБ, вложение до 200 МиБ. Фоновая синхронизация требует включённого «Быть в сети в фоне». После принудительной остановки Android приложение нужно открыть вручную.
