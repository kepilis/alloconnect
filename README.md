# AlloConnect для Android 0.16.19

[Скачать APK для ARM64](alloconnect_android-0.16.19-arm64-v8a.apk?raw=1)

Если прямой канал до друга недоступен, приложение пробует отправить текст через привязанный ПК. Нужна Windows 1.22.28 или новее. Исправлено отображение синхронизированной переписки.

APK обновляет 0.16.17 и 0.16.18 новой линейки `com.alloconnect.alo`. С 0.16.16 установите новый APK вручную отдельным приложением. У каждой установки своё локальное хранилище.
