# AlloConnect для Windows 1.22.33

Исправлены список согласуемых профилей H.264 и выбор профиля для аппаратного кодирования. Прежние профили сохранены для совместимости. Для нового профиля обновите оба ПК.

Проверка запуска демонстрации теперь ждёт свежие кадры и подтверждает аппаратное кодирование по обновившейся статистике. Начальные отчёты с размером 0×0 или старыми счётчиками не вызывают мгновенного отказа.

В диагностике сохраняются профиль, фактический кодировщик и результат проверки.

Обновление доступно через «Проверить обновления».
