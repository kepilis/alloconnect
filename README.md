# alloconnect — обновление 1.21.13

Режим редактирования саундпада и стикеров: выделение нескольких элементов, категории и контекстные действия. Приглашение в групповой звонок по коду без добавления в друзья. Исправлены статусы, настройки, панель загрузок и контраст шумоподавления в теме «Лён».

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой. Инструменты YouTube скачиваются проверяемым служебным пакетом при первом использовании.
