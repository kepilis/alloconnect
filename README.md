# alloconnect — обновление 1.21.17

Вход в YouTube прямо из alloconnect: отдельная сессия без расширений и чтения профилей Chrome/Brave. Вход предлагается при необходимости, затем загрузка продолжается автоматически. Сессия сохраняется на этом ПК с шифрованием Windows; доступны вход и выход в Настройки → Демонстрация экрана → Перенос ссылок с YouTube.

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой. Инструменты YouTube скачиваются проверяемым служебным пакетом при первом использовании.
