# alloconnect — обновление 1.22.1

Исправлено создание кода общего аккаунта при наличии в истории записей о файлах больше 200 МиБ. Размеры и записи истории сохраняются; лимит хранения оригиналов не применяется к метаданным передач.

Обновите также Android до 0.16.1, чтобы телефон принимал историю больших файлов. Метаданные передач сохраняются с исходными размерами. Отсутствующие локально оригиналы не восстанавливаются из записи истории.
