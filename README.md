# alloconnect — обновление 1.22.2

Исправлены создание кода общего аккаунта при наличии истории файлов больше 200 МиБ и резервное копирование записей с уже удалёнными оригиналами. История и исходные размеры файлов сохраняются.

Обновите также Android до 0.16.2, чтобы телефон принимал историю больших файлов. Метаданные передач сохраняются с исходными размерами. Отсутствующие локально оригиналы не восстанавливаются из записи истории.
