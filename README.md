# alloconnect — обновление 1.21.14

Кнопка загрузок находится в верхней панели справа от статуса соединения и остаётся доступной во время демонстрации, в том числе в групповом звонке. Громкость звука демонстрации сохраняется между звонками и после перезапуска программы.

Подпись Ed25519, размеры и SHA-256 проверяются перед установкой. Инструменты YouTube скачиваются проверяемым служебным пакетом при первом использовании.
