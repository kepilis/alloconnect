# AlloConnect для Windows 1.22.34

В групповом звонке убрана лишняя кнопка саундпада с главного экрана.

Кнопка «Позвонить» другому человеку во время личного или группового звонка завершает текущий разговор и начинает новый личный вызов. В переписке с текущим собеседником кнопка отключена.

Обновление доступно через «Проверить обновления».
