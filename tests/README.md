# Автотесты

Запускались на Linux под Xvfb, на одной машине работают два экземпляра программы.
В скриптах пути заменены на заглушки, перед запуском их нужно подставить:
`<TEST_ROOT>` — рабочая папка тестов, `<ELECTRON>` — путь к electron из node_modules, `<SRC>` — папка с исходниками.

Общий принцип: тестовый `main` (h*.js / harness4.js) делает `require('./main.js')` настоящей программы,
дальше управляет окном через `executeJavaScript`. Два экземпляра договариваются через файлы-флажки в общей папке (`SHARED`).
Переменные программы для тестов: `ALOCALLS_USERDATA` (отдельная папка данных — второй экземпляр не блокируется),
`ALOCALLS_FAKE_HELPER` (подставной помощник вместо exe), `ALOCALLS_UPDATE_DIR` (папка «установленных» файлов при проверке обновлений),
`ALOCALLS_GH_RAW` / `ALOCALLS_GH_API` (подставной GitHub для проверки обновлений).
Профили двух тестовых «друзей» (identity.json + friends.json в ud/A и ud/B) создаются один раз обычным добавлением в друзья.

- `two-windows/harness4.js` + `run.sh` — основной набор регрессии: звонок по коду и из друзей, STUN-переключение,
  чат и файлы, история, аватарки, приглушение, рисование/реакции, управление (через `fake-helper.js`), саундпад.
  Несколько пунктов зависят от среды (srflx на подставном STUN, история) — сравнивать с прошлой версией, а не с нулём.
- `two-windows/h7.js` — видео на экран друга (лимиты, место/размер, громкость с обеих сторон). Тестовые видео — ffmpeg (testsrc).
- `two-windows/h8.js` — чат: реакции, ответ с цитатой, правка, удаление, подделка правки, поиск, история.
- `two-windows/h9.js` — вёрстка в маленьком окне (кнопки на месте, ничего не наезжает), скриншоты.
- `two-windows/h11.js` — темы оформления во всех окнах, сохранение выбора, загрузка шрифтов.
- `stun/fake-stun.js` — подставной STUN-сервер (должен слушать LAN-адрес, не 127.0.0.1).
- `update/` — обновление от друга (hu.js + go.sh) и с GitHub (hg.js + fake-github.js): подпись, хэши, отказ при подделке, установка подставным помощником.
- `ident/run.js` + `h-ident.js` — подтверждение ID в звонке по коду (1.15.1): честный звонок, самозванец с чужим ID,
  «старая версия» без доказательства, звонок из списка друзей. Работает и на Windows: `node tests/ident/run.js`;
  `APP_FROM=<распакованный app.asar>` — проверить собранную программу.

## group (ветка test/multicall)
`node tests/group/run.js` — четыре экземпляра, дружба A–B, A–C, B–D (остальные записки идут через участников). Проверяет: соединение каждый с каждым, голос, чат (ответ, реакция, правка, чужое не удаляется), экран со звуком (и настоящий экран со звуком компьютера через помощник), уменьшенное видео для маленьких плиток, рисунок/указка/реакции поверх чужого экрана, саундпад, файл всем, микрофон, приглашение не от создателя, переподключение после обрыва, уход создателя и участника, повторный сбор сохранённой группы с историей чата, отказ самозванцу (неверное подтверждение ID), управление (один управляющий на показывающего), встречная сборка одной группы. `SHOT=1` — снимок окна.

`node tests/two-windows/run.js [папка] [исходники]` — harness4.js на Windows (код идёт через общий файл вместо системного буфера обмена).
